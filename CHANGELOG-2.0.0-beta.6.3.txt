觅阅 2.0.0-beta.6.3 修改记录

本版在 beta.6.2 的 Android 下载稳定性修复基础上，处理微信读书接口返回 -10102“请求频率受限”时直接中断下载的问题。

一、请求频率保护
1. 明确识别 error_code=-10102、-2014、HTTP 429/499 和 Hit api rate limit。
2. 下载过程中主动放慢连续接口请求，降低再次触发限制的概率。
3. 触发限制后按 15 秒、30 秒、60 秒分段等待并自动重试。
4. 服务端返回 Retry-After 时，优先采用更长的等待时间，最长 180 秒。
5. 等待期间持续更新下载进度，界面会显示剩余秒数，不再像卡死。
6. 等待期间可以正常取消下载。

二、失败保护
1. 自动等待后仍受限时停止继续请求，避免对后续章节反复轰炸接口。
2. 已完成章节、图片和断点缓存继续保留，再次下载只补未完成内容。
3. 不再显示 http.lua 文件路径和英文接口错误，改为明确的中文提示。
4. 原有完整 EPUB 不会被覆盖或删除。

三、兼容性
1. 仅下载任务启用长时间自动等待，书架等前台操作不会被锁住一两分钟。
2. Kindle、Kobo 和 Android 共用识别逻辑；Android 下载任务使用更保守的请求间隔。
3. beta.6.2 的下载结果恢复、子进程判断和诊断保留逻辑全部保留。

四、版本
版本号：2.0.0-beta.6.3
数据结构版本：50
