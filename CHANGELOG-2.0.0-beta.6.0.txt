觅阅 · 微信读书助手 2.0.0-beta.6.0 修改记录
================================================

基础版本
--------
基于 2.0.0-beta.5.9 继续完善。本版将此前列为“下一版加入”和“后续再做”的插件内可实现项目尽量合并完成，重点包括 Android 书架/搜索/封面异步、普通 EPUB 持久化排除、跨分区安全安装、想法真实分页和书架排序降级。未推倒重写下载器、书架界面或 EPUB 格式。

一、Android 书架、搜索与封面
--------------------------
1. Android 搜索改为优先使用可取消的后台子进程。
   - 搜索窗口关闭或用户取消后，会终止对应子进程并清理结果文件。
   - Android 后台任务无法启动时，不再退回界面线程执行长网络请求，而是提示稍后重试，避免界面假死。

2. Android 账号书架刷新改为优先使用后台子进程。
   - 关闭、切换或重新打开书架时，会使旧任务失效并取消旧子进程。
   - 返回结果前会核对刷新代次，旧任务不能覆盖新页面。
   - Android 后台任务不可用时，不再悄悄阻塞主界面；已有缓存仍可继续显示。

3. Android 封面下载改为后台逐张处理。
   - 仅为当前页逐张加载，不一次启动大量网络请求。
   - 翻页或关闭书架后，立即取消当前封面任务。
   - 子进程启动连续失败后跳过当前封面，不再无限循环重试。
   - Android 后台子进程不可用时跳过未缓存封面，优先保证书架可操作。

4. Async 任务取消逻辑加强。
   - 同时取消轮询定时器、终止子进程并清理正式与临时结果文件。
   - 增加 Android 平台识别方法，便于避免主线程阻塞式降级。

二、普通 EPUB 持久化负缓存
------------------------
1. 普通 EPUB 首次确认不属于觅阅后，会记录：
   - 规范化文件路径；
   - 文件大小；
   - 修改时间；
   - 最近确认时间。

2. KOReader 重启后，只要文件大小和修改时间没有变化，觅阅会直接忽略该普通 EPUB：
   - 不再次解压检查 miuread.json；
   - 不启动远程进度、阅读时间或书籍识别重试；
   - 日志降为 debug，不再产生“识别失败”警告。

3. 文件发生变化、被移动到觅阅记录中，或检测到有效觅阅身份后，会自动清除负缓存。
4. 缓存最多保留 256 项，并清理长期未使用或文件已经不存在的记录。
5. 非 EPUB 文件在进入身份解析前直接排除。

三、跨分区与外置存储安全安装
--------------------------
1. EPUB 安装不再只依赖 os.rename。
   - 同一分区时优先原子重命名。
   - 跨分区重命名失败时，改为 256 KB 分块复制到目标目录的临时文件。

2. 复制完成后进行安全校验。
   - 检查复制前后文件大小一致。
   - EPUB 文件继续使用原有 ZIP/EPUB 完整性校验。
   - 校验不通过时删除临时文件，保留原文件和旧书。

3. 替换已有目标文件时增加回滚保护。
   - 先将旧目标移动到同目录临时备份；
   - 新文件安装成功后才删除旧备份；
   - 安装失败时自动恢复旧目标。

4. 最终 EPUB 和“关闭当前书后再安装”的待安装文件均使用同一安全流程。
5. 日志会记录本次采用 rename 还是 copy，便于定位外置 SD 卡或跨分区问题。

四、想法弹窗真实分页
------------------
1. 将原有但未接入界面的分页算法正式用于想法弹窗。
2. 每页最多处理少量评论，并按文字量进一步拆分超长评论。
3. 当前弹窗只生成当前页 HTML，不再把所有评论一次性拼成巨型 HTML。
4. 增加“上一页 / 当前页数 / 下一页”控件，并支持有按键设备翻页。
5. 切页时释放上一页的 HTML、正文摘录、按钮和页码部件，降低 MuPDF 内存压力。
6. 评论按 reviewId 去重；缺少 reviewId 时按作者和正文组合去重。
7. 保留原有字体、弹窗宽高、正文摘录和评论视觉样式，没有重新设计界面。

五、书架排序降级与日志精简
------------------------
1. 刷新书架后统计可用排序字段覆盖率。
2. 当至少约 60% 的书具有可靠阅读更新时间时，使用阅读时间排序。
3. 当至少约 60% 的书具有明确顺序字段时，使用明确顺序排序。
4. 字段覆盖不足时保持接口原始顺序，不再依据零散字段强行猜测官方顺序。
5. 置顶书仍优先显示。
6. 日志只输出一次排序模式、书籍数量和字段覆盖统计，不再宣称“官方顺序已恢复”。
7. 本地账号书架合并时保留已解析的云端顺序，不再重复猜测。

六、Android 后台下载能力说明
--------------------------
1. 沿用 beta.5.9 已有能力：
   - 后台下载子进程；
   - 防重复点击；
   - PID、任务令牌和结果文件接管；
   - 周期断点保存；
   - 下载中重新登录后的旧 cookie 回写保护；
   - KOReader 内部下载完成/失败提示。

2. 下载期间继续使用 KOReader 的 preventStandby 机制，并在任务结束后成对释放。
3. 本版没有强行修改设备全局自动休眠设置，避免覆盖用户原有偏好。
4. 真正的 Android 原生前台 Service 和系统通知栏仍需要修改 KOReader Android 原生层，不属于纯 Lua 插件包能够安全完成的范围。

七、继承并保留 beta.5.9 稳定性修复
--------------------------------
1. 403 后只进行一次登录恢复和真实验证，失败后整次批注任务熔断。
2. 识别 429、499、-2014 和“请求频率超限”，禁止限流后拆成大量单条请求。
3. 划线或想法失败时，正文完整即可降级生成纯净版。
4. 批注中途失败后重新由原始正文构建全书，避免半批注半纯净的混合 EPUB。
5. 保留“批注待补”断点，后续补批注无需重新下载正文。
6. 降级纯净版不会覆盖已有完整“划线与想法版”。
7. 正文、目录或必要章节缺失时，仍严格拒绝生成残缺 EPUB。
8. 阅读时间认证/上下文错误暂停，网络/服务器错误指数退避，失败时长本地累计后补传。
9. suspend 阶段不进行最终网络上传。
10. 阅读时间服务同一本书幂等启动，同一阅读会话最多自动重启一次。
11. 后台下载结果使用账号、登录时间和认证版本快照，旧子进程不能覆盖新登录。
12. 正确称呼 plugins/weread.koplugin 为“原作者 WeRead 插件”，不自动删除或禁用。

八、版本与包结构
--------------
1. 版本号更新为 2.0.0-beta.6.0。
2. 数据结构版本更新为 schema 49，用于普通 EPUB 持久化负缓存。
3. 包内不包含 .md、.git、测试脚本或临时文件。
