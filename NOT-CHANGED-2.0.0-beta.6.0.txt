觅阅 · 微信读书助手 2.0.0-beta.6.0 暂未修改项目
====================================================

以下项目没有在本版中宣称解决。部分超出纯 Lua 插件权限，部分属于其他插件或 KOReader 本体，部分仍需要真实设备数据。

一、需要 KOReader Android 原生层支持
----------------------------------
1. 真正的 Android 原生前台 Service。
   - 纯 Lua 插件无法自行注册长期运行的 Android Foreground Service。
   - 本版继续使用子进程、preventStandby、断点和重新进入后的任务接管作为替代。

2. Android 系统通知栏通知。
   - 当前仍是 KOReader 内部提示。
   - 下载完成后在应用完全不活动时显示系统通知，需要 KOReader Android 原生桥接接口。

3. Android 系统强制清理进程。
   - 系统极端省电或厂商后台限制仍可能杀死 KOReader及其子进程。
   - 本版能够恢复断点，但不能保证进程永远不被系统终止。

二、KOReader 或设备底层问题
------------------------
1. 输入事件 Broken pipe 高速循环。
   - 根源位于 KOReader 输入层、设备事件管道或 HIDPassthrough。
   - 觅阅已减少休眠和关闭阶段的后台活动，但没有修改 KOReader 输入循环。

2. 缺少原生调用栈的 Segmentation fault 和 Killed。
   - 已改善觅阅 worker、定时器、子进程和 suspend 生命周期。
   - 没有原生调用栈时，不能保证所有系统级崩溃已经定位。

3. 所有 Android 厂商受限存储和权限组合。
   - 本版已加入跨分区复制、校验和回滚。
   - 仍无法绕过系统拒绝授予的外置 SD 卡或受限目录写权限。

三、明确不属于觅阅
----------------
1. 原作者 WeRead 插件：
   - [WeRead]、plugins/weread.koplugin，版本 0.3.5、0.4.0、0.5.0；
   - 原作者插件的 403/499、想法内存、阅读上报、更新和 weread2.koplugin 方法缺失。

2. QuickUI 的 ipairs 类型错误。
3. WebDAV 404。
4. KOReader 字体注册警告。
5. CloudStorage 未配置。
6. Kobo 平台异常唤醒。

四、仍保留的功能边界
------------------
1. 微信读书官方书架绝对顺序。
   - 本版会按字段覆盖率选择可靠排序或 API 原始顺序。
   - 当服务器不返回官方排序字段时，无法保证与官方客户端逐项完全一致。

2. 想法真正的逐条虚拟列表。
   - 本版已实现真实分页和当前页渲染，已经避免一次构建全部评论。
   - 尚未实现可复用行部件的无限虚拟滚动列表；目前没有必要为此重写整个弹窗。

3. 下载器整体架构重写。
   - 当前下载器已具备任务熔断、正文保护、断点、降级、跨分区安装和后台接管。
   - 本版继续局部加固，没有重新设计 EPUB 格式、书架界面、评论样式或主要菜单。

五、仍需实机验证
--------------
1. 不同 Android 版本上搜索、书架和封面子进程是否均能正常启动、取消和回收。
2. Android 切后台、Activity/UI 重建及系统杀进程后的下载断点恢复。
3. 外置 SD 卡和不同存储提供者上的复制、校验、替换及回滚。
4. Kindle/Kobo 按键设备上的想法翻页布局和按键行为。
5. 超长评论、多页评论和低内存设备上的 MuPDF 内存表现。
6. 服务器排序字段覆盖率不同账户下的书架顺序。
7. beta.5.9 所列的批注熔断、纯净版降级、阅读时间补传和登录快照保护场景。
